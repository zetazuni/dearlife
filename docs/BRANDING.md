DEARLIFE — Branding Directions
================================

TITLE
-----
Dearlife

SUBTITLE PAIRING OPTIONS
------------------------
- Dearlife: A Story of Your Own
- Dearlife: Everyday Moments

LOGO / VISUAL TONE
------------------
- Handwritten or letter-style font
- Small heart, envelope, or diary motif as an icon
- Warm, cozy color palette to match the "personal diary" feel

IN-GAME FRAMING IDEAS
----------------------
- Lean into a "dear diary" narrative style
- Character milestones displayed as journal entries
- Save files styled like a memory book / scrapbook
- Consider small flourishes like handwritten notes, doodles, or stamps
  in the UI to reinforce the diary/letter concept
